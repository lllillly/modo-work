# 프론트 테스트 케이스

기준은 `feat/front/document-search` 브랜치, 로컬 백엔드와 NLP는 최신 main입니다. 데스크탑은 1440px, 모바일은 400px입니다.

담당이 **직접**인 항목은 화면에서 손으로 확인하고, **자동**인 항목은 스크립트로 확인합니다. 결과는 `통과`, `실패`, `보류` 중 하나로 적고, 실패하면 비고에 무엇이 달랐는지 적습니다.

시험 계정은 개발용 데이터의 계정을 씁니다.

| 역할 | 계정 |
| --- | --- |
| 관리자 | `admin01@example.com` |
| 리더 | `lead01@example.com` |
| 담당자 | `user01@example.com` |
