## 본문

### 변경 내용

- 할 일 상세에서 담당자 중 비활성 사용자가 있으면 "담당자 바꾸기" 버튼 표시 (리더, 관리자, 미완료 할 일만)
- 담당자 바꾸기 창에서 현재 담당자와 비활성 표시 확인, 같은 조직과 영역의 후보를 검색해 대신 맡을 사람 선택
- 저장 시 비활성 담당자만 빼고 정상 담당자와 다른 영역 배정은 그대로 유지해 전체 배정으로 전송
- 배정 정보 조회에서 권한이 없거나 바꿀 수 없는 과정이면 안내만 표시, 409면 최신 배정을 다시 불러옴
- 리더 홈 알림의 "재배정 필요"(#158)를 누르면 이 상세로 이어지는 흐름
- 화면 문서의 과정별 할 일 설명에 교체 기능 추가

### 검증 결과

- `npm run lint`, 타입 검사 통과
- 관리자 계정에서 비활성 담당자가 있는 할 일에 버튼이 보이고, 후보를 골라 저장하면 비활성 담당자만 바뀐 전체 배정이 전송되는 것 확인 (영역 1의 비활성 담당자만 교체, 영역 3 배정 유지)
- 리더 계정에서 교체 권한이 없는 과정이면 서버 403 안내가 창에 표시되는 것 확인
- PC 1440px과 모바일 400px에서 상세 패널과 창 확인
- 실제 데이터에 비활성 담당자가 없어 할 일과 배정 응답을 바꿔서 확인했고, 저장 요청은 서버로 보내지 않고 요청 내용만 확인
