## 본문

### 변경 내용

- 헤더 종 아이콘이 비어 있던 것을 홈 API의 알림(기한 지남, 임박 할 일)으로 채웠습니다. 배지는 전체 건수, 목록은 10건까지 보여 주고 나머지는 홈으로 안내합니다
- 리더와 관리자는 리더 홈, 그 외는 담당자 홈 알림을 씁니다. 홈 화면을 나누는 기준과 같습니다
- 알림을 누르면 해당 할 일로 이동하고, 종을 열 때와 화면을 옮길 때 다시 불러옵니다

### 검증 결과

- `npm run lint`, 타입 검사 통과
- 관리자 계정에서 배지 40건과 목록 10건, 담당자 계정에서 2건 확인
- 알림을 누르면 할 일 화면으로 이동하고 창이 닫히는 것 확인
- 400px 폭에서 창이 화면 안에 들어오는 것 확인

- 알림함 API가 없어서 읽음 처리는 없습니다. 홈 알림과 같은 목록을 보여 주는 방식입니다
