# 홈과 과정별 할 일

## 로그인

`AuthProvider`가 사용자와 로그인 상태를 들고 있고, `RequireAuth`가 업무 화면에 들어올 수 있는지 확인합니다. 로그인 화면은 인증 상태에 따라 입력 폼이나 안내 화면을 보여 줍니다.

`src/api/auth.ts`는 시험 로그인, 내 정보 조회, 로그아웃을 부릅니다. 로그인 상태는 `/me`와 서버의 인증 오류로 확인합니다.

## 담당자 홈과 리더 홈

`HomePage.tsx`가 역할에 따라 두 홈 중 하나를 보여 줍니다.

- `AssigneeHomePage.tsx`는 알림, 달력, 날짜별 할 일, 과정 진행률을 보여 줍니다.
- `LeaderHomePage.tsx`는 요약, 확인 범위, 알림, 처리 기록, 과정별 진행률을 보여 줍니다.
- `assigneeHomeData.ts`, `leaderHomeData.ts`는 홈 API 응답을 화면에서 쓰는 모양으로 바꿉니다.

두 홈은 `TaskList`를 같이 씁니다. 건수, 진행률, 다음 할 일은 서버가 센 값을 그대로 보여 줍니다.

**담당자 홈**
- 날짜별 할 일은 선택한 날짜를 마감 범위로 넘겨 불러옵니다. 달을 넘기면 그 달의 달력 집계를 새로 받습니다.
- 내 영역과 전체 보기 전환은 다른 영역 열람이 허용된 경우에만 보입니다.
- 다시 불러오는 동안에는 이전 화면을 그대로 둡니다.

**리더 홈**
- 확인은 한 건이면 확인 API, "모두 확인"이면 일괄 확인 API를 씁니다.
- 확인 버튼은 서버가 준 `canReview`로 보여 주고, 확인 범위 밖의 할 일은 보기만 가능합니다.
- 확인 범위 표시는 `roles[].orgUnit`과 `roles[].area`를 씁니다.
- 마감 배지는 한국 날짜로 계산하고, 임박은 서버 알림에 들어 있는 할 일만 표시합니다.

## 과정별 할 일

`TasksPage.tsx`가 과정 선택과 태그 필터를 맡고, `ApiCourseTasks.tsx`가 서버 데이터를 불러와 `courseTasksApiData.ts`에서 화면용으로 바꿉니다.

| 컴포넌트 | 역할 |
| --- | --- |
| `TaskPhaseList.tsx` | 단계별 목록, 진행률, 완료 목록 접기 |
| `TaskDetailDrawer.tsx` | 상세 정보, 처리 버튼과 기록, 메모 입력 |
| `MonthlyWork.tsx` | 월 주기와 상시 업무 |
| `CourseSchedule.tsx` | 일정 표시와 수정, 변경 이력 |

처리 요청에는 서버의 `version`과 요청마다 만드는 `requestId`를 보냅니다. 마감과 월 주기는 서버에 저장된 값을 그대로 보여 줍니다. 일정을 수정할 권한이 없으면 일정 조회가 403이라 수정 버튼 없이 보여 줍니다.
