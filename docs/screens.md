# 화면과 연동 상태

모두 실제 API에 연결돼 있고, 연결하지 않은 부분은 맨 아래에 따로 적었습니다.

| 화면 | 주소 | 하는 일 |
| --- | --- | --- |
| 로그인 | `/login` | 시험 로그인, 내 정보 조회, 로그아웃 |
| 홈 (담당자) | `/` | 알림, 달력, 날짜별 할 일 완료, 과정 진행률 |
| 홈 (리더, 관리자) | `/` | 요약, 알림, 처리 기록과 확인, 과정별 진행률 |
| 과정별 할 일 | `/tasks` | 단계별 할 일, 상세, 완료와 메모, 일정과 월 주기 |
| 과정과 담당 배정 | `/admin/courses` | 목록, 등록, 수정, 삭제, 보관 목록과 복원 |
| CSV 가져오기 | `/admin/courses/import` | 미리보기, 적용, 취소 |
| 물어보기 | `/ask` | 질문, 되묻기 후보 선택, 근거 표시 |
| 문서 | `/documents` | 목록, 종류 필터, 제목과 본문 검색, PDF 보기, 버전 기록 |
| 문서 업로드 | `/admin/documents` | PDF와 외부 링크 등록, 파일 교체, 버전 복원, 삭제 |
| 사용자와 승인 | `/admin/users` | 승인 대기, 사용자 목록, 역할 수정, 목록 관리 |
| 할 일 템플릿 | `/admin/task-templates` | 목록, 추가와 수정, 사용 켜고 끄기, 태그 관리 |
| 물어보기 관리 | `/admin/questions` | 답 없음 질문, 의도, Q&A, 통계, 평가 |
| 휴무일 설정 | `/admin/settings` | 공휴일 조회, 회사 휴무일 추가와 수정, 삭제 |
| 서비스 토큰 | `/admin/service-tokens` | 발급한 토큰 목록, 발급, 폐기 |
| 설정 내보내기와 가져오기 | `/admin/config` | 종류별 파일 내려받기, 미리보기, 적용 |

`/tasks`에서 `courseId`가 없으면 진행 중인 첫 과정을 엽니다. 관리자는 관리자용 과정 API로, 리더와 담당자는 홈 API의 과정 목록으로 과정을 고릅니다.

## 만들지 않은 것

- **공지와 교육**: 백엔드 요구사항에서 빠져서 화면이 없습니다(11-25 답변).
- **알림함**: 알림함 API가 없어서 홈 API의 알림(기한 지남, 임박 할 일)을 헤더 종 아이콘에 같이 보여 줍니다. 10건까지 보여 주고, 나머지는 홈에서 봅니다. 읽음 처리는 없습니다.
- **감사 기록**: API만 있고 화면은 없습니다. 설계서에 메뉴가 없습니다.
- **임박 기준과 알림 시각**: 설정 API가 없어 화면 없이 서버 환경변수(`MESSENGER_DUE_SOON_BUSINESS_DAYS` 등)로 바꿉니다. 확신 기준값 같은 물어보기 설정값도 화면 없이 설정 가져오기 파일로만 바꿉니다.
- **문서의 연결된 할 일, 문서 업로드의 템플릿 연결**: 아직 비활성입니다.
